Breakfast Orders 2.0.34 Expressive preview - Flutter / Material 3 Expressive
Windows 10/11, 64-bit

Extract the whole ZIP, then open breakfast_orders.exe. Keep the data folder and
DLLs beside the executable. No Flutter, Node, Electron or Visual Studio install
is required to run this package. Edge, Chrome or Firefox is needed for printing.

UPDATING FROM AN EARLIER FLUTTER PREVIEW
Your existing Flutter profile, settings and saved password are reused.
Versions 2.0.26–2.0.29 need manual replacement to fix their updater. Close any leftover breakfast_orders.exe background instance before replacing files.
Close the app, then extract the complete new application folder. Do not delete
your separate %APPDATA%\Breakfast Orders Flutter profile.

Reliable update helper launch, with Update available first in the toolbar.

FIRST RUN FROM ELECTRON AND EXISTING DATA
Close the old Breakfast Orders app before your first launch.
On first launch this version copies orders, menu, safe cabins, pending email
imports, aliases and duplicate history from %APPDATA%\Breakfast Orders into
%APPDATA%\Breakfast Orders Flutter. The original profile is never modified.
The copy happens once. Later changes in the two apps are not synchronized.

Re-enter your mail password in Email settings, connect and list folders, choose
the exact folder, then Test connection & save / Save & check. Automatic checks
are paused during migration. Passwords are protected by your Windows account.

If data is on another computer, use Settings > Backup & restore > Restore data with a 1.22.2 JSON
backup. Back up data exports menu, accepted orders, safe cabins and preferences;
it excludes mail credentials and the pending email queue. For complete recovery,
close the app and copy the entire Flutter profile folder. Keep its .bak files
and backups folder. Windows account changes may require password re-entry.

PRINTING
Choose Print > All printouts, Orders only, Selected orders, Delivery schedule,
Item totals or Expanded timetable. The existing browser print layout is retained.
Use A4 landscape, 100% scale and turn off headers and footers. If the dialog
does not open automatically, click Print on the browser page or press Ctrl+P.

PREVIEW VALIDATION
Automated tests cover data compatibility, email parser/service behavior, the
real IMAP client against a simulated server, UI workflows, and compact layouts.
All print modes and a long-order fixture were compared with 1.22.2 in Chrome.
Windows credential encryption was tested in the compiled application.
Your actual mail server/login and physical printer still need a local check.

ROLLBACK
The old app and its profile remain intact. New orders entered in Flutter are
not automatically copied back. Export a Flutter data backup and restore it in
1.22.2 if you need to transfer accepted orders back. Its saved mail password and
pending review history remain separate; do not run automatic importing in both
apps during the same service.

Source, build instructions and validation details are in the companion source.
Third-party license notices are in licenses/, THIRD-PARTY-NOTICES.txt and
