Breakfast Orders 2.0.28

- Fixed the portable updater stopping at 100%: the Windows helper now starts reliably and survives application shutdown. Launch and rollback checks run before every release.
- Update available is now the leftmost toolbar action.
- Portrait Items overview and Timetable, empty zero-quantity cells and alternating category-tinted rows.
- Split delivery slips show a warning and slip count at the bottom of every part.
- Minimal Print / Save PDF fallback page, with automatic closing after printing where the browser allows it.
- Smaller dialog headers, sharper corners, Settings page titles and Save beside Close. About and dark mode sit at the bottom of the sidebar.
- Order received/creation date and time beside guest details and on delivery slips. Older manual orders without timestamps remain unchanged.

Download the Windows ZIP, extract the complete folder, and run breakfast_orders.exe.
Versions 2.0.26 and 2.0.27 need this one manual replacement because their updater launcher is faulty. Close the app before replacing its files. Saved orders and settings are stored separately and retained. This preview is unsigned.
